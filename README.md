# weslley-de-oliveira.github.io

Portfólio de Weslley de Oliveira Machado, publicado em <https://weslley-de-oliveira.github.io>.

Página estática em HTML, CSS e um pouco de JavaScript, sem framework nem build: o GitHub Pages publica a `main` como está.

- `index.html`: o conteúdo.
- `assets/styles.css`: tema claro e escuro (segue o sistema, com alternância salva no navegador).
- `assets/main.js`: alternância de tema e entrada suave das seções.
- `assets/img/`: capturas dos projetos.

Para ver localmente, abra o `index.html` no navegador ou rode `npx serve .`.
