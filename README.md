# weslley-de-oliveira.github.io

Portfólio de Weslley de Oliveira Machado, publicado em <https://weslley-de-oliveira.github.io>.

Página estática em HTML, CSS e um pouco de JavaScript, sem framework nem build: o GitHub Pages publica a `main` como está. Layout inspirado em [tajmirul.site](https://www.tajmirul.site/).

- `index.html`: início, sobre, stack, experiência, projetos e contato.
- `projetos/`: uma página por projeto, com destaques, números e capturas.
- `assets/styles.css`: tema escuro por padrão e tema claro opcional (a escolha fica salva no navegador).
- `assets/main.js`: menu, tema, fundo de estrelas, progresso da rolagem, prévia dos projetos e entrada suave.
- `assets/icons/`: ícones das tecnologias, do [Devicon](https://devicon.dev) (MIT).
- `assets/img/`: foto e capturas dos projetos.

Ao mudar o CSS ou o JS, suba o `?v=` das referências nos HTML para o navegador não usar a versão em cache.

Para ver localmente, abra o `index.html` no navegador ou rode `npx serve .`.
